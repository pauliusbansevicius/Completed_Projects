### 2. IoT Weather Monitoring Station (Low-Power Data Logger)
A portable, battery-powered environmental monitoring device designed for long-term data collection in remote locations.
* **The Goal:** Measure and log atmospheric conditions (Temperature, Humidity, Pressure) with minimal energy consumption.
* **Hardware Highlights:**
    * **Microcontroller:** Standalone ATmega328P-PU.
    * **Display:** 2.13” E-Paper module (maintains image without power).
    * **Sensors:** DHT22, BMP180, and DS3231SN RTC for precise time-stamping.
    * **Power System:** 3.7V LiPo with TP4056 charging and MCP1700-3302E LDO regulator.
* **Key Features:** Integrated battery voltage monitoring via ADC and data logging to a microSD card.
* **Result:** A compact, PCB-ready design utilizing SMD components for industrial-grade portability.
